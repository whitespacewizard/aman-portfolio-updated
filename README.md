# Aman Raj Portfolio

Open the folder in VS Code and run `index.html` with Live Server.

## Pages

- `index.html` - Homepage
- `portfolio.html` - Full portfolio listing
- `quick-clean.html` - Quick Clean case study
- `accountx.html` - AccountX case study

## Global Components

- `components/menu.html` - Shared desktop and mobile menu used on every page
- `components/footer.html` - Shared footer used on every page
- `assets/js/components.js` - Loads the global menu and footer, then starts the existing site JavaScript

To update menu text, links, email, phone number or footer copy across the whole website, edit the relevant file inside `components/`.

Use Live Server or normal web hosting. Browser security may block component loading when an HTML file is opened directly with a `file:///` URL.

## Styles

- `assets/css/common.css` - Shared navigation, homepage, footer and responsive styles
- `assets/css/portfolio.css` - Portfolio listing page
- `assets/css/quick-clean.css` - Quick Clean case study
- `assets/css/accountx.css` - AccountX case study

## JavaScript

- `assets/js/components.js` - Global component loader
- `assets/js/main.js` - Mobile menu, auto-hide navigation, smooth scrolling and copy-email behavior

## Images

- `assets/images/` - Local portrait and company-logo assets

Keep the file structure unchanged so all links, styles, components and images continue to work.
